## Revisión de seguridad explícita

| Área                               | Defensa revisada                                                                                                                               |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Secrets / logs / audit             | Private key fuera de DB/API; Token/Sign solo memoria; errores y logger sin causes/cuerpos; tests deliberados de fuga.                          |
| Directory traversal / tenant leaks | UUIDs, prefijo de tenant, resolve/realpath, symlinks rechazados, archivos sin rutas elegidas por cliente; HTTP 404 ajeno.                      |
| Upload                             | Límite BFF/Express/base64/bytes, X.509 real, rechazo múltiples PEM/ZIP/PFX/privadas, vigencia y key match.                                     |
| SSRF                               | Endpoint WSAA server-side, allowlist literal y redirects error; URL de navegador rechazada.                                                    |
| XXE                                | Sin DTD/ENTITY/resolución externa; parser acotado y contrato del XML.                                                                          |
| Shell / command injection          | execFile sin shell, nombres fijos, args separados; subject escapado y campos acotados.                                                         |
| TLS                                | Sin rejectUnauthorized=false ni NODE_TLS_REJECT_UNAUTHORIZED=0; HTTPS/hostname de Node.                                                        |
| CSRF / permission boundaries       | Origin exacto y header global en API/BFF; ADMIN y sesión/tenant revalidados.                                                                   |
| Race conditions                    | Advisory por org, expectedVersion, índices únicos activo/pendiente, generation operationId/hash, single-flight y reserva durable previa a red. |

Es una revisión de implementación con pruebas locales, no certificación de producción. Los ensayos usan solo material sintético. No se afirmó que WSAA real funcione.

Logs locales ignorados por Git: `artifacts/arca-lint.log`, `arca-format.log`, `arca-typecheck.log`, `arca-test.log`, `arca-database.log`; también `artifacts/arca-build.log`, `arca-migration-status.log` y `arca-drift.log`. Los secretos no se registran como evidencia.
